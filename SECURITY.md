# Security Policy

## Reporting a vulnerability

If you find a security issue in this repository — most importantly a leaked
credential, token, session ID, or customer-identifying information — please
report it privately via GitHub's "Report a vulnerability" feature (Security
tab) instead of opening a public issue.

We will acknowledge and remove/rotate affected material as quickly as
possible.

## Scope notes

- This repository contains documentation, scripts, and reference apps; it does
  not run a hosted service.
- The reference apps are designed for deployment to **your own** Domo
  instance. Review an app's README and provisioning scripts before deploying
  to a production instance.
- Never commit your own Domo credentials when forking or adapting this
  material.
