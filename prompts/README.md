# Request Templates

Copy-paste templates for handing work to an AI coding agent. Fill in the
bracketed sections and paste the whole thing as your request.

| Template | Use it when |
|---|---|
| [implementation-request-template.md](implementation-request-template.md) | Asking an agent to implement a change |
| [review-request-template.md](review-request-template.md) | Asking an agent to review a branch / PR / diff |
| [prompt-revision-request-template.md](prompt-revision-request-template.md) | Asking an agent to revise a Domo AI prompt (Code Engine / Workflow) safely |

These are the same templates the authors use internally; the "Must Read" lists
point at this repository's `AGENTS.md` and `skills/` so the agent grounds
itself before touching anything.
