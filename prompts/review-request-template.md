# Review Request

## Must Read

- `README.md`
- `AGENTS.md`
- `skills/code-review.md`
- Relevant project README or `AGENT.md`

## Review Target

Branch, PR, diff, files, or pasted code to review.

## Review Focus

- Correctness.
- Existing behavior compatibility.
- Public function and manifest alias compatibility.
- Domo deployment or data mutation risk.
- Secret exposure.
- Error handling and logging.
- Test coverage and validation gaps.
- AI-agent prompt or output-schema ambiguity.

## Required Output

- Findings first, ordered by severity.
- File and line references where possible.
- Open questions.
- Validation gaps.
- Deploy readiness: yes / no / blocked, with reason.
