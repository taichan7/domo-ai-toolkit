# AIサマリー 共通規約（一貫性コントラクト）

> **このファイルは4本のAIプロンプトの「単一の真実」です。** ETL テキスト生成タイル（短文）と Workflow AI エージェント（長文・AppDB）が、同じ月次データから **矛盾しない結論** を出すための共通ルールを定義します。数値・状態判定・問題店舗の選び方をここで一元管理し、各プロンプトは必要部分を自プロンプト内に転記します（Domo の各面はプロンプトを個別に保持するため、ランタイム include はできない）。

## 対象プロンプト（この規約を転記して従う4本）

| # | 面 | 生成物 | 正本 | 粒度 |
|---|----|--------|------|------|
| 1 | ETL タイル `店舗別AIサマリー生成`（action 6） | 短文（`店舗別AIサマリー`列） | [prompt_dataflow_store_summary.md](prompt_dataflow_store_summary.md) | 店舗 |
| 2 | ETL タイル `全社AIサマリー生成`（action 8） | 短文（`全社AIサマリー`列） | [prompt_dataflow_company_summary.md](prompt_dataflow_company_summary.md) | 全社 |
| 3 | 統合サブWF `report_type="store"` 分岐（店舗レポートAI） | 長文 `analysis_html`（AppDB） | [prompt_wf02_store.md](prompt_wf02_store.md) | 店舗 |
| 4 | 統合サブWF `report_type="company"` 分岐（全社サマリーAI） | 長文 `analysis_html`（AppDB） | [prompt_wf03_summary.md](prompt_wf03_summary.md) | 全社 |

> 旧 WF-02（店舗）/ WF-03（全社）の2本のサブ Workflow は、`report_type` 分岐を持つ**1本の統合サブ Workflow**（Model `cf3b78c2-…`）へ統合済み。ファイル名は履歴の都合で `prompt_wf02_store.md` / `prompt_wf03_summary.md` のままだが、それぞれ統合サブWFの店舗／全社ブランチの指示文を指す。

**変更時のルール**: 状態ラベルの5値・閾値は SQL タイル `SQL｜要約集計（店舗×月）` の `CASE` 式（出力 `状態ラベル` 列）が**正本**。変えるときは ①SQL の `CASE`、②この規約、③4本のプロンプトの「参考・判定規則」注記 を揃えて更新し、DataFlow を再実行 → WF-01 を2回連続実行して、短文（`店舗別AIサマリー`列）と長文（AppDB `analysis_html`）の状態ラベル一致を再検証すること。

> **⚠予約識別子 `store_id = "ALL"`（BK-003）**: `ALL`（大文字小文字を問わない）は**全社集計レポート専用の予約 `store_id`／`doc_key` 先頭トークン**。全社ブランチが `doc_key = "ALL-{period}-{scenario}"` を発行する。個別店舗の `store_id` に `ALL` を割り当ててはならない。割り当てると店舗レポートの `doc_key` が全社レポートと byte 単位で衝突し、保存 CE の重複除去（同一 `doc_key` の**厳密に古い**版を物理削除）がどちらか片方を period×scenario ごとに恒久削除する。CE は保存時に全社／店舗を区別できない（`report_type` は保存ドキュメントに含まれないルーティング変数）ため、**データ所有者が店舗マスタで `ALL` を欠番**にすること（または WF-01 の店舗一覧クエリで `store_id <> 'ALL'` を除外する）。

## 1. 数値の扱い（全プロンプト共通）
- 入力データ（またはツール取得結果）の値のみを使用。丸め・概算・創作をしない。
- 金額は **円単位・桁区切り**（例: `1,234,567円`）。比率は小数第1位（例: `24.8%`）。
- 欠損は `取得不可` と明記。存在しない指標に言及しない。

## 2. 状態ラベル（利益率で一意に決定）
同じ利益率なら短文・長文で**必ず同じラベル**になるよう、数値閾値で判定する。

### 2.1 全社（4値）
| ラベル | 条件（全社利益率） |
|--------|------------------|
| 好調 | 利益率 ≥ 8.0% |
| 堅調 | 5.0% ≤ 利益率 < 8.0% |
| 要注意 | 0.0% ≤ 利益率 < 5.0% |
| 不振 | 利益率 < 0.0%（全社赤字） |

> 「黒字/赤字」という語を**状態ラベルとして使わない**（黒字/赤字は補足説明で使ってよいが、状態判定語は上記4値に統一）。

### 2.2 店舗（5値）
| ラベル | 条件 |
|--------|------|
| 好調 | 利益率 ≥ 8.0% |
| 堅調 | 5.0% ≤ 利益率 < 8.0% |
| 要注意 | 0.0% ≤ 利益率 < 5.0% |
| 回復基調 | 利益率 < 0.0% **かつ** `前月比利益変化率` > 0（赤字だが前月比で純利益が改善） |
| 不振 | 利益率 < 0.0% **かつ** `前月比利益変化率` ≤ 0（赤字かつ前月比で悪化・横ばい） |

> **状態ラベルは「単一の真実」＝ ETL の決定的列。LLM は再判定しない（一貫性の要）**
> 状態ラベルは DataFlow `2042` の SQL タイル `SQL｜要約集計（店舗×月）` の `CASE` 式で**機械的に確定**され、出力データセットの **`状態ラベル`** 列として保存される（上表の5値・閾値と一致）。回復基調／不振の分岐に使う `前月比利益変化率`(%) は前月純利益からの増減率で、正 = 改善。この符号のみで決まり、**赤字の深さや改善幅の大小ではラベルは変わらない**。
> - **ETL 短文タイル**（`店舗別AIサマリー生成`）は `ai_input_text` に含まれる `状態ラベル` の値を**そのまま**使う。
> - **統合サブWF（店舗ブランチ）の長文エージェント**は入力 JSON の `state_label`（= `状態ラベル`、WF-01 の店舗別クエリで別名付与）を**そのまま**使う。
>
> これにより異なるモデル（ETL の `domogpt-medium` と統合サブWF（店舗ブランチ）の Claude 系エージェント）が**同じ月次データから必ず同じ状態ラベル**を返す。過去、両者に境界判定（例: 利益率 -8% だが前月比改善は「回復基調」か「不振」か）を委ねると恣意的に食い違った（短文 0/28・長文 7/28 等）。判定を ETL 列に一元化し、両 LLM は転記に徹することで構造的に解消した。**状態ラベルの規則を変えるときは SQL の `CASE` 式（正本の定義）を変更し、この規約と各プロンプトの「参考・判定規則」注記を追随させる。**

## 3. 支配要因の語彙（3値に統一）
利益を左右した最大要因を、短文・長文で同じ語で結論づける。
| 語 | 判定の目安 |
|----|-----------|
| 売上不足 | 前年同月比/地域比で売上が劣後し、費用の売上比は過大でない |
| コスト構造過剰 | 売上は概ね確保しつつ、特定費用（商品原価・総人件費・施設費・管理費用等）の売上比が過大 |
| 売上・コスト両面 | 上記が同時に成立 |

## 4. 問題店舗の指標（全社サマリー：短文2・長文4で共通）
全社サマリーで「要介入店舗」を名指しする際は、**純利益ワースト（赤字・低収益）を最優先の指標**とする。
- 全社純利益を直接毀損しているのは赤字・低収益店舗であり、経営の第一関心と一致する。
- 短文（`PY｜AI入力用テキスト結合` の `純利益下位`）と長文（統合サブWF 全社ブランチの `DomoSqlQueryTool` で純利益昇順）が**同じ店舗集合**を指すようにする。
- **予算差異は「全社集計値」（全社売上予算差異・原価予算差異）としてのみ言及**し、予算差異ベースの別店舗リストを作らない（黒字なのに予算差異ワーストという矛盾を避ける）。

> 店舗レポート（長文・店舗単位）の「予算差異ワースト**勘定科目**」は店舗内の勘定分析であり、全社の店舗選定とは独立。従来どおり予算差異ベースでよい。

## 5. KPI 定義（両面で同一計算）
- 利益率(%) = 純利益 / 総売上 × 100
- 人件費比率(%) = 総人件費 / 総売上 × 100
- 黒字店舗数 = 純利益 > 0 の店舗数 / 全店舗数
- 費用内訳: 商品原価・総人件費・施設費・マケ費用・管理費用（売上比で最大の圧迫項目を特定）

## 6. 期待される一貫性（検証観点）
WF-01 実行後、以下が短文・長文で一致すること:
1. 全社状態ラベル（例: 5.4% → 両方「堅調」）
2. 全社の要介入店舗＝純利益ワースト（両方が同じ下位店舗を名指し）
3. 各店舗の状態ラベル（同一店舗で短文と長文が同じ5値）
4. KPI（利益率・人件費比率・黒字店舗数）
5. 支配要因の語（3値のいずれかで一致）
