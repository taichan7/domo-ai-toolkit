# Skills Library

Task-specific operating notes for AI coding agents (and humans) working on Domo.
Each file is a self-contained skill: read the one matching your task before you start.

> **Provenance note:** these skills were extracted from the authors' original internal
> workspace. Claims tagged `[REPO]` cite files in that workspace as evidence; some of
> those paths (internal project folders) are not bundled here. Treat them as
> provenance for *how a fact was verified*, not as files you can open. Everything
> tagged `[DOC]` cites Domo's published documentation.
> Internal review transcripts and coordination workflows are not included.
> A documentation review is not live verification on your instance.
